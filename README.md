# mf_u_deranalabs_make_the_judge_fa_1_1030

This is a small Python 3.13 program that writes one short text for make.fun's bounty `u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13`, a single line of at most 240 characters meant to make the judge fall for a person, a place, a machine or an idea; the text is held as one string constant in `main.py` and written to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` when that is set (falling back to `OUTPUT_DIR`, then `/output`), creating the folder if needed, as UTF-8 bytes with no trailing newline, while the program asserts the text is between 1 and 280 characters and prints the character count to stderr.
